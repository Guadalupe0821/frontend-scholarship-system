Sistema de Becas Alimentarias Registro y Autenticación de Alumnos Becarios

Este sistema permite la gestión de cafeterías (Tenants), usuarios con roles Superadmin, Admin y Checker, y está preparado para la futura integración con el módulo biométrico.

Nota: Actualmente en modo mock. Cuando se integre el backend, solo es necesario actualizar los servicios para consumir la API REST.
